# Constructors & `this`

## Constructors
- Initialize an object when it is created.
- Must have the same name as the class and **no return type**.
- Invoked during object creation, e.g. `new Student("Asha")`.
- Constructors are not inherited or overridden and cannot be called like ordinary methods.

## Default Field Values
Instance fields receive default values:
- Numeric primitives: `0` (or `0.0`)
- `boolean`: `false`
- Reference types: `null`

Local variables do not receive automatic default values; they must be initialized before use.

## Default vs. No-Arg Constructor
- If a class declares **no constructor**, the compiler provides a default no-argument constructor.
- If any constructor is declared, the compiler does not generate that default constructor.
- A programmer can explicitly declare a no-argument constructor.

## Parameterized Constructors
Accept values to initialize an object during creation.

```java
class Student {
    String name;
    int age;

    Student(String name, int age) {
        this.name = name;
        this.age = age;
    }
}
```

## Constructor Overloading
Multiple constructors can coexist if their parameter lists differ.

```java
Student() {
    this("Unknown", 0);
}

Student(String name, int age) {
    this.name = name;
    this.age = age;
}
```

## `this` Keyword
- Refers to the current object instance.
- Disambiguates instance fields from parameters: `this.name = name`.
- `this()` invokes another constructor in the same class and must be the first statement in traditional constructor syntax.

## Important Gotchas
- Constructors have no return type—not even `void`. A method named after the class with a return type is an ordinary method.
- Constructor overloading depends on parameter lists, not return types.
- You cannot invoke a constructor directly on an existing object to reinitialize it.
- `new` can fail with `OutOfMemoryError` if the JVM cannot allocate the required memory.
