# Nested Classes

A **nested class** is a class declared inside another class or interface. It helps with logical grouping, encapsulation, and implementation details.

Java has four main types:

1. Static nested classes
2. Non-static inner classes
3. Local classes
4. Anonymous classes

## 1. Static Nested Class
- Declared using `static` inside another class.
- Does not require an instance of the outer class.
- Can directly access only the outer class's static members; instance members require an outer object reference.
- Can declare static members.
- Useful for helper classes and builder implementations.

```java
class Outer {
    private static int count = 10;
    private int value = 20;

    static class Nested {
        void display() {
            System.out.println(count);
            // value requires an Outer instance
        }
    }
}

// Creation
Outer.Nested obj = new Outer.Nested();
```

## 2. Non-Static Inner Class
- Declared inside a class without `static`.
- Each inner object is associated with an enclosing outer object.
- Can access all members of that outer object, including private members.
- Historically, a non-static inner class could not have static methods because it is explicitly tied to an instance of its enclosing (outer) class, creating a fundamental logical paradox.
- However, this is no longer completely true: **starting with Java 16, non-static inner classes are officially allowed to have static methods**
  
```java
class Outer {
    private int value = 10;

    class Inner {
        void display() {
            System.out.println(value);
        }
    }
}

// Creation
Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();
```

Use `Outer.this` inside the inner class to explicitly refer to the enclosing outer instance.

## 3. Local Class
- Declared inside a method, constructor, or block.
- Accessible only within its enclosing scope.
- Can access enclosing instance members when an enclosing instance exists.
- Local variables and parameters captured from the enclosing scope must be `final` or **effectively final**.

```java
void process() {
    int limit = 10; // Effectively final

    class Worker {
        void run() {
            System.out.println(limit);
        }
    }

    new Worker().run();
}
```

A local variable is effectively final if it is not reassigned after initialization.

## 4. Anonymous Class
- An unnamed class declared and instantiated in one expression.
- Commonly used for a one-off implementation of an interface or extension of a class.
- Can access enclosing members and effectively final local variables.
- Cannot declare an explicit constructor because it has no class name.

```java
Runnable task = new Runnable() {
    @Override
    public void run() {
        System.out.println("Running");
    }
};

task.run();
```

For a functional interface, a lambda is often shorter:

```java
Runnable task = () -> System.out.println("Running");
```

Lambdas are not anonymous classes; they have different language semantics, particularly for `this`.

## Quick Comparison

| Type | Requires outer instance? | Where declared |
|---|---|---|
| Static nested | No | Inside a class, with `static` |
| Inner | Yes | Inside a class, without `static` |
| Local | Depends on enclosing context | Inside a block or method |
| Anonymous | Depends on the enclosing context | Inline expression |

## Key Gotchas
- A static nested class is associated with the outer class, not a particular outer object.
- An inner class has an enclosing outer-instance reference, which can affect object lifetime and memory retention.
- Nested classes can access private members of the enclosing class.
- Local classes and anonymous classes capture local variables only when they are final or effectively final.
- Prefer a lambda over an anonymous class when implementing a functional interface and no class-specific behavior is needed.
- Static nested classes are often preferable to inner classes when no outer-instance access is required.
