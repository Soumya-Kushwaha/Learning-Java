# Inheritance

## Core Concept
- Inheritance models an **is-a** relationship between a subclass and superclass.
- `extends` lets a class inherit accessible members and behavior from a superclass.
- Benefits: code reuse, specialization, and runtime polymorphism.

```java
class Animal {
    void sound() {
        System.out.println("Animal sound");
    }
}

class Dog extends Animal {
    @Override
    void sound() {
        System.out.println("Bark");
    }
}
```

## Supported Class Inheritance
- **Single:** One superclass → one subclass.
- **Multilevel:** `A → B → C`.
- **Hierarchical:** Multiple subclasses extend the same superclass.
- Java classes do not support multiple inheritance of classes; a class can directly extend only one class.
- A class can implement multiple interfaces.

## `super` Keyword
- `super.field`: accesses an accessible superclass field hidden by a subclass field.
- `super.method()`: invokes the superclass implementation of an instance method.
- `super(...)`: invokes a superclass constructor and must be the first statement in traditional constructor syntax.
- If omitted, Java inserts `super()` only when an accessible no-argument superclass constructor is available.

## Important Gotchas
- Constructors are not inherited.
- Private members are not directly accessible in subclasses; private methods are not overridden.
- Every class except `Object` ultimately has a superclass.
- Use `@Override` to let the compiler verify intended method overriding.
- Prefer composition over inheritance when the relationship is not genuinely **is-a**.
