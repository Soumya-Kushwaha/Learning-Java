# Queue, Deque & PriorityQueue

## 1. Queue Fundamentals

A `Queue` is a collection designed to hold elements before processing.

- **FIFO (First-In-First-Out):** The first element inserted is the first one removed.
- Common implementations use arrays or linked lists.

Example: A queue of tasks is processed in the order in which tasks arrive.

### Queue vs Stack

| Feature | Queue | Stack |
|---|---|---|
| Principle | FIFO | LIFO |
| Insertion | At the rear | At the top |
| Removal | From the front | From the top |
| Example | Task scheduling | Undo operations |

- **FIFO:** First element added is removed first.
- **LIFO (Last-In-First-Out):** Last element added is removed first.

Both queues and stacks can be implemented using arrays or linked lists.

## 2. Java Queue Hierarchy

`Queue` and `Deque` are interfaces in the Java Collection Framework.

```text
Iterable
   |
Collection
   |
   +------------------+
   |                  |
  List              Queue
                      |
                    Deque
                      |
             +--------+--------+
             |                 |
         ArrayDeque        LinkedList
```

Important implementations:

| Implementation | Description |
|---|---|
| `ArrayDeque` | Resizable-array implementation of `Deque` |
| `LinkedList` | Implements both `List` and `Deque` |
| `PriorityQueue` | Retrieves elements according to priority |

### Deque

`Deque` means **Double-Ended Queue**.

It allows insertion and removal at both ends.

It can be used as:
- A queue (FIFO).
- A stack (LIFO).

`ArrayDeque` is commonly preferred over the legacy `Stack` class for stack operations.

## 3. Queue Interface Methods

Queue operations are grouped into three categories.

| Operation | Exception-throwing method | Special-value method |
|---|---|---|
| Insert | `add(e)` | `offer(e)` |
| Remove | `remove()` | `poll()` |
| Inspect front | `element()` | `peek()` |

### Insertion

```java
queue.add(10);
queue.offer(20);
```

- `add(e)`: Inserts an element. Throws an exception if insertion is not possible.
- `offer(e)`: Attempts insertion and returns `false` if it cannot insert.

### Removal

```java
queue.remove();
queue.poll();
```

- `remove()`: Removes and returns the head. Throws an exception if the queue is empty.
- `poll()`: Removes and returns the head. Returns `null` if the queue is empty.

### Inspection

```java
queue.element();
queue.peek();
```

- `element()`: Returns the head without removing it. Throws an exception if the queue is empty.
- `peek()`: Returns the head without removing it. Returns `null` if the queue is empty.

### Exception vs Special-Value Methods

| Situation | Exception-throwing method | Special-value method |
|---|---|---|
| Insertion fails | `add()` throws exception | `offer()` returns `false` |
| Queue is empty during removal | `remove()` throws exception | `poll()` returns `null` |
| Queue is empty during inspection | `element()` throws exception | `peek()` returns `null` |

**Remember:** `offer()`, `poll()`, and `peek()` are useful when you want to handle unsuccessful operations without relying on exceptions.

## 4. PriorityQueue

A `PriorityQueue` is a specialized queue in which elements are retrieved according to priority rather than insertion order.

Unlike a normal FIFO queue, the element with the highest priority according to the queue's ordering is retrieved first.

Java's `PriorityQueue` uses a **heap** internally.

```java
import java.util.PriorityQueue;

PriorityQueue<Integer> queue = new PriorityQueue<>();

queue.offer(30);
queue.offer(10);
queue.offer(20);

System.out.println(queue.peek()); // 10
System.out.println(queue.poll()); // 10
```

By default, Java's `PriorityQueue` uses natural ordering, so the smallest element has the highest priority.

A custom `Comparator` can change the ordering.

## 5. Heap Data Structure

A heap is a complete binary tree that follows a heap-order property.

Two common types:

### Min-Heap

- Parent is smaller than or equal to its children.
- The smallest element is at the root.

```text
       10
      /  \
    20    30
   /  \
  40  50
```

### Max-Heap

- Parent is greater than or equal to its children.
- The largest element is at the root.

```text
       50
      /  \
    40    30
   /  \
  10  20
```

**Important:** A heap is not a fully sorted tree. It only maintains the parent-child ordering property.

## 6. Heap Operations

A heap maintains its property after insertion and removal using two operations.

### Up-Heapify (Insertion)

When a new element is inserted:

1. Insert it at the next available position to maintain the complete binary tree.
2. Compare it with its parent.
3. Swap if the heap property is violated.
4. Continue upward until the property is restored or the root is reached.

For a min-heap, a child smaller than its parent moves upward.

### Down-Heapify (Removal)

When the root is removed:

1. Replace the root with the last element.
2. Remove the last position.
3. Compare the replacement with its children.
4. Swap with the appropriate child if the heap property is violated.
5. Continue downward until the property is restored.

For a min-heap, swap with the smaller child when necessary.

## 7. PriorityQueue Complexity

For a binary heap:

| Operation | Time Complexity |
|---|---:|
| `peek()` | O(1) |
| `offer()` / insertion | O(log n) |
| `poll()` / removal of head | O(log n) |
| `remove(Object)` | O(n) |
| `contains(Object)` | O(n) |

The logarithmic insertion and removal costs come from moving through the height of the heap.

## 8. Important Java Notes

- `PriorityQueue` does not guarantee that iteration traverses elements in sorted order. Only the head is guaranteed to be the next element according to its ordering.
- `PriorityQueue` does not permit `null` elements.
- It is not synchronized; it is not designed for concurrent modification by multiple threads without external coordination.
- A custom `Comparator` can define priority instead of natural ordering.
- `ArrayDeque` is a common choice for implementing stack behavior instead of the legacy `Stack` class.

## Interview Quick Revision

1. **What is FIFO?** First-In-First-Out; the first inserted element is removed first.
2. **What is LIFO?** Last-In-First-Out; the last inserted element is removed first.
3. **What is a Deque?** A double-ended queue that supports insertion and removal at both ends.
4. **Difference between `add()` and `offer()`?** `add()` throws an exception on insertion failure; `offer()` returns `false`.
5. **Difference between `remove()` and `poll()`?** `remove()` throws an exception on an empty queue; `poll()` returns `null`.
6. **Difference between `element()` and `peek()`?** Both inspect the head; `element()` throws on an empty queue, while `peek()` returns `null`.
7. **What is a PriorityQueue?** A queue that retrieves elements according to priority rather than arrival order.
8. **What is a Min-Heap?** A complete binary tree where each parent is less than or equal to its children.
9. **What is a Max-Heap?** A complete binary tree where each parent is greater than or equal to its children.
10. **What is up-heapify?** Restoring heap order by moving an inserted element upward.
11. **What is down-heapify?** Restoring heap order by moving the replacement root downward.
12. **Why is heap insertion O(log n)?** The element can move up at most the height of the heap.
13. **Why is `peek()` O(1)?** The highest-priority element is stored at the root.
14. **Does PriorityQueue iteration return sorted elements?** No. Its iterator does not guarantee sorted order.
