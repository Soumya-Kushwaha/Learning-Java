# Enums

An `enum` is a special Java type representing a **fixed set of constants**. It provides better type safety and readability than using arbitrary `int` or `String` constants.

## 1. Why Enums?

Using `int` or `String` constants allows invalid values to be passed accidentally. Enums restrict values to the declared constants.

```java
enum Status {
    PENDING, PAID, FAILED
}

Status status = Status.PENDING;
```

- Improves type safety and readability.
- Common uses: order/payment status, days of the week, log levels, and predefined categories.
- Enum constants are objects, not primitive values or strings.

## 2. Fields, Constructors & Methods

Enums can have fields, constructors, methods, and implement interfaces.

```java
enum PaymentStatus {
    PENDING("Waiting"),
    PAID("Completed"),
    FAILED("Unsuccessful");

    private final String description;

    PaymentStatus(String description) {
        this.description = description;
    }

    public String getDescription() {
        return description;
    }
}
```

```java
PaymentStatus status = PaymentStatus.PAID;
System.out.println(status.getDescription()); // Completed
```

- Enum constructors cannot be `public` or `protected`; they are effectively private.
- Enum constants are initialized when the enum class is initialized.
- Enums cannot extend another class because they already extend `java.lang.Enum`; they can implement multiple interfaces.
- An enum can override methods, including methods differently for individual constants.

## 3. Built-in Methods

| Method            | Purpose                                                                                         |
| ----------------- | ----------------------------------------------------------------------------------------------- |
| `values()`        | Returns an array of all enum constants in declaration order.                                    |
| `valueOf("PAID")` | Returns the constant with the exact matching name; otherwise throws `IllegalArgumentException`. |
| `name()`          | Returns the exact declared constant name.                                                       |
| `ordinal()`       | Returns the zero-based declaration position.                                                    |
| `toString()`      | Returns the constant's string representation; can be overridden.                                |

```java
PaymentStatus.valueOf("PAID"); // PaymentStatus.PAID
PaymentStatus.PAID.name();     // "PAID"
PaymentStatus.PAID.ordinal();  // 1
```

**Important distinctions:**

- `values()` is a compiler-generated static method; it is not inherited from `java.lang.Enum`.
- `valueOf(String)` is compiler-provided for each enum type.
- `name()` and `ordinal()` are inherited from `java.lang.Enum`.
- Avoid persisting or relying on `ordinal()` as a business identifier. Reordering constants changes ordinals.
- Use `name()` when you specifically need the declared constant name; `toString()` may return customized text.

## 4. Enum Internals

- Every enum implicitly extends `java.lang.Enum`.
- Each declared constant is a unique instance of that enum type.
- Enum constructors are not directly callable by application code.
- Enum constants are commonly compared using `==` because each constant is a unique instance.

```java
if (status == PaymentStatus.PAID) {
    // Handle successful payment
}
```

## 5. Enums with `switch`

Enums work naturally with `switch` statements and expressions.

```java
switch (status) {
    case PENDING -> System.out.println("Waiting");
    case PAID -> System.out.println("Done");
    case FAILED -> System.out.println("Try again");
}
```

The arrow syntax is supported in modern Java. Use syntax appropriate to the project's Java version.

## Interview Quick Revision

- Prefer enums over `int` or `String` constants for a fixed set of valid choices.
- Enums can contain fields, constructors, methods, and implement interfaces.
- Enum constructors cannot be public or protected.
- `values()` returns all constants; `valueOf()` looks up a constant by exact name.
- `ordinal()` is declaration position, not a stable business ID.
- Enum constants can be compared with `==`.
- Enums cannot extend a user-defined class, but they can implement interfaces.
