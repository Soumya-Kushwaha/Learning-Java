# Arrays, Methods & Recursion

## Arrays
- Fixed-size, zero-indexed; elements have the same declared type.
- `.length` gives array size (field, not method).
- Invalid index → `ArrayIndexOutOfBoundsException`.
- Indexed access: O(1); traversal: O(n).
- Multidimensional arrays are arrays of arrays; rows can have different lengths.

```java
int[] arr = {3, 1, 2};

Arrays.sort(arr);
Arrays.toString(arr);           // "[1, 2, 3]"
Arrays.equals(arr, new int[]{1, 2, 3});
Arrays.binarySearch(arr, 2);    // Requires sorted array
```

Import: `java.util.Arrays`

## Methods
- Java has methods, not standalone functions.
- Parameters are declared in the method signature; arguments are passed at invocation.
- `void` indicates no return value.
- **Pass-by-value:** Java passes copies of values, including object references.
- **Overloading:** Same method name, different parameter lists; return type alone cannot distinguish overloads.
- `static` methods belong to the class; instance methods operate in an object context.

```java
static int add(int a, int b) {
    return a + b;
}
```

## Recursion
- A method calling itself directly or indirectly.
- Requires a base case and progress toward termination.
- Each call consumes stack space; deep recursion can cause `StackOverflowError`.

```java
static int factorial(int n) {
    if (n <= 1) return 1;
    return n * factorial(n - 1);
}
```
