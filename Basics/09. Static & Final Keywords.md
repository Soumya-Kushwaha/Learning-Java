# Static & Final Keywords

## `static` Keyword

A `static` member belongs to the **class**, rather than to individual instances.

### Static Variables
- One shared copy per class, rather than a separate field in each instance.
- Useful for class-wide state or shared constants.

```java
class Student {
    static String college = "ABC";
    String name;
}
```

Access using `Student.college` (preferred) or an instance reference.

### Static Methods
- Can be called using the class name without creating an instance.
- Can directly access only static members.
- Cannot use `this` or `super` because they require an instance context.
- Can call instance methods if they have an object reference.

```java
class Utility {
    static int square(int n) {
        return n * n;
    }
}

// Usage
int result = Utility.square(5);
```

### Static Blocks
- Execute when the class is initialized, before its static members are used for the first time as part of that initialization.
- Useful for complex static initialization.
- Multiple static blocks execute in source-code order.

```java
class Config {
    static final int LIMIT;

    static {
        LIMIT = 100;
    }
}
```

## `final` Keyword

### Final Variables
- Must be assigned exactly once.
- A `final` field must be initialized at declaration, in an instance initializer, or in a constructor, as appropriate.
- A `static final` field is commonly used for a class-level constant.

```java
static final double PI = 3.14159;
```

### Final References
A `final` reference cannot point to a different object after assignment, but the referenced object may still be mutable.

```java
final List<String> names = new ArrayList<>();
names.add("Asha");              // Allowed
// names = new ArrayList<>();   // Compilation error
```

### Final Methods & Classes
- `final` method: cannot be overridden in a subclass.
- `final` class: cannot be extended.
- Constructors cannot be declared `final`.

## The `main()` Method

```java
public static void main(String[] args)
```

- `public`: accessible to the launcher.
- `static`: can be invoked without creating an instance.
- `void`: returns no value.
- `String[] args`: command-line arguments passed to the program.

Example: `java Main hello 123` passes `"hello"` and `"123"` in `args`.

## Key Gotchas
- `static` members are shared at the class level; they are not duplicated for each object.
- Static methods are hidden, not overridden, when a subclass declares a matching static method.
- `final` prevents reassignment; it does not automatically make an object immutable.
- `static final` is commonly used for constants; compile-time constants generally require a primitive or `String` constant expression.
- Static initialization happens once per class initialization, not once per object.
